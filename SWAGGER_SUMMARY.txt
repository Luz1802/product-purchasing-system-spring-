│ 🎨 RESUMEN VISUAL DE ANOTACIONES                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  @Tag                                                                       │
│  ├─ Nivel: Clase (sobre @RestController)                                  │
│  ├─ Función: Agrupar endpoints relacionados                                │
│  └─ Ejemplo: @Tag(name = "Productos", description = "...")                │
│                                                                             │
│  @Operation                                                                 │
│  ├─ Nivel: Método                                                          │
│  ├─ Función: Describir operación específica                                │
│  └─ Ejemplo: @Operation(summary = "...", description = "...")             │
│                                                                             │
│  @Parameter                                                                 │
│  ├─ Nivel: Parámetro del método                                            │
│  ├─ Función: Documentar cada parámetro                                      │
│  └─ Ejemplo: @Parameter(name = "...", description = "...", example = "...")│
│                                                                             │
│  @ApiResponse                                                               │
│  ├─ Nivel: Método (dentro de @ApiResponses)                                │
│  ├─ Función: Definir una respuesta HTTP                                    │
│  └─ Ejemplo: @ApiResponse(responseCode = "200", ...)                      │
│                                                                             │
│  @ApiResponses                                                              │
│  ├─ Nivel: Método                                                          │
│  ├─ Función: Agrupar múltiples respuestas                                  │
│  └─ Ejemplo: @ApiResponses({ ... })                                       │
│                                                                             │
│  @Content                                                                   │
│  ├─ Nivel: Dentro de @ApiResponse                                          │
│  ├─ Función: Especificar tipo MIME y estructura                            │
│  └─ Ejemplo: @Content(mediaType = "...", schema = @Schema(...))           │
│                                                                             │
│  @Schema                                                                    │
│  ├─ Nivel: Clase o propiedad                                               │
│  ├─ Función: Definir estructura de datos                                   │
│  └─ Ejemplo: @Schema(implementation = Producto.class)                     │
│                                                                             │
│  @ArraySchema                                                               │
│  ├─ Nivel: Dentro de @Content                                              │
│  ├─ Función: Especificar array de objetos                                  │
│  └─ Ejemplo: @ArraySchema(schema = @Schema(...))                          │
│                                                                             │
